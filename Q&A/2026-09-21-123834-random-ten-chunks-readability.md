# Q&A — ความได้ใจความของ 10 chunks ที่สุ่มจาก RAG

## คำถาม

สุ่มดึงสัก 10 chunk ขึ้นมาดูว่า แต่ละ chunk นั้นอ่านแล้วได้ใจความมั้ย

## คำตอบ

สุ่ม **10 จาก 907 chunks** ผ่าน MCP พอร์ต 8976 แล้วครับ **ผมอ่านประเมินเอง พบว่าได้ใจความไม่สม่ำเสมอ** บางชิ้นอ่านเข้าใจ แต่ยังต้องเรียกบริบทเพิ่มก่อนนำไปอ้างอิง

| # | Paper / หน้า PDF | ข้อความที่พบและผลประเมิน |
|---|---|---|
| 1 | DeepSeek-V4 / 48 | **เป็นบรรณานุกรม** อ่านชื่อผลงานได้ แต่ไม่ใช่เนื้อหาผลวิจัย รายการสุดท้ายถูกแบ่งจนเหลือเพียงชื่อผู้แต่ง |
| 2 | Meta-Harness / 8 | **ได้ใจความหลัก** เรื่องการค้นหาและประเมิน harness แต่เริ่มกลางประโยคว่า “be able to exploit at inference time.” ส่วนผลทดลองอ้าง Table 6 ซึ่งไม่ได้อยู่ใน chunk |
| 3 | Natural-Language Agent Harnesses / 4 | **อ่านหลักการเขียน NLAH ได้ชัด** แต่ข้อสุดท้ายจบที่ `clauses such as “write` แล้วติดเลขหน้า `4` ประโยคต่ออยู่หน้าถัดไป |
| 4 | DeepSeek-V4 / 21 | **ส่วน activation checkpointing อ่านเข้าใจ** แต่ต้นชิ้นเป็นข้อความต่อจากหน้าก่อน และรวมเนื้อหาคนละหัวข้อไว้ด้วยกัน |
| 5 | Externalization in LLM Agents / 50 | **เป็นบรรณานุกรม** มีรายการ OpenAI, MemGPT และงานอื่น ใช้ตามหาแหล่งอ้างอิงได้ แต่ไม่มีข้อค้นพบของบทความในชิ้นนี้ |
| 6 | Natural-Language Agent Harnesses / 3 | **ประโยคครบและเข้าใจหน้าที่แต่ละชั้น** แต่เริ่มด้วย “The second layer” แล้วเล่าชั้น 2–4 โดยไม่มีชั้นแรกหรือภาพรวม |
| 7 | LinearRAG / 7 | **ตารางอ่านยาก** หัว benchmark ยังอยู่ แต่ตัวเลขแต่ละช่องเรียงลงมาเป็นบรรทัด ต้องนับและจับคู่เอง อีกทั้ง caption อยู่นอก chunk |
| 8 | DeepSeek-V4 / 17 | **เรื่อง Z3 อ่านเข้าใจ** แต่เปิดหัวข้อ numerical precision ต่อ แล้วจบกลางประโยคที่ “TileLang provides” คำอธิบายต่ออยู่หน้าถัดไป |
| 9 | Qwen3-Omni / 17 | **บริบทตารางไม่ครบ** มีตัวเลขจาก Table 17 แต่ไม่มีชื่อโมเดลที่เป็นหัวคอลัมน์ แล้วปนต้น Table 18 ก่อนตัดที่ “GTZAN Acc.” |
| 10 | Qwen3-VL / 38 | **ได้ใจความตามประเภทข้อความ** เป็นตัวอย่าง prompt ระบุ benchmark, input และรูปแบบ output ชัด ใช้ตรวจรูปแบบ prompt ได้ แต่ไม่ใช่ผลการทดลอง |

ผลรอบนี้แบ่งเป็น **1 ชิ้นครบตามประเภทข้อความ, 5 ชิ้นต้องเพิ่มบริบท, 2 ชิ้นมีปัญหาตาราง และ 2 ชิ้นเป็นบรรณานุกรม** ไม่ควรนำสัดส่วนจากตัวอย่างเล็กนี้ไปแทนคุณภาพทั้งระบบ

ทั้ง 10 ชิ้นตรงกับข้อความหน้าที่ระบบสกัดไว้ แต่ **การตรงต้นฉบับไม่ได้แปลว่า chunk มีใจความครบ** จุดที่ควรปรับต่อคือประโยคข้ามหน้า การรักษาหัวตารางกับตัวเลข และการแยกบรรณานุกรมออกจากเนื้อหา
